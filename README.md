# HCMI Website

Free static website prepared for GitHub Pages.

## Updating concerts
Open `events-data.js` in GitHub, click the pencil icon, and edit the event list. Commit the change. GitHub Pages will republish automatically.

## Publishing
1. Create a new public GitHub repository (for example `hcmi-website`).
2. Upload all files and the `assets` folder from this package.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. GitHub will provide a temporary `github.io` address for previewing.
5. After previewing, add your Porkbun domain under Settings → Pages → Custom domain. GitHub will show the DNS records to add at Porkbun.
